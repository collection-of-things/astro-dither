# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them through GitHub's private vulnerability reporting on this repository (the Security tab, "Report a vulnerability"), or contact the maintainer through their GitHub profile.

We will acknowledge the report, investigate, and follow up with a fix or an answer as soon as we can.
